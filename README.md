# TD-110 Maelstrom Tank Gun Editor

A configurable Helldivers 2 mod for the TD-110 Maelstrom.

Features:
- Main cannon ammo and spare belts
- Main cannon reload speed
- Main cannon RPM
- Smoke capacity and firing delay
- Rear missile capacity
- Config hot reload
- Multi-Maelstrom support

Requires:
- [Bingus Shared Loader](https://github.com/CowboyBingus/BingusSharedLoader)

## Download

[Download the latest release](https://github.com/OnlyTanks/TD-110-Maelstrom-Gun-Editor/releases/latest)

## Configuration

Edit `MaelstromAmmo.cfg` to change the Maelstrom settings.
